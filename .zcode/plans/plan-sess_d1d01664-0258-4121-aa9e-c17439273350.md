# Windows 客户端按 web 端重构（UI + 功能对齐）

## Context

web 端（server/src/webapp，纯 JS PWA）经过多轮迭代已是成熟形态：侧边栏 IA（时间线/探索/相册/分享/收藏夹/回收站 + 管理区）、顶部搜索、头像菜单、统一设计系统（CSS 变量 + Lucide 风 SVG 图标）、多选批量栏、右键菜单、灯箱工具栏、分享（有效期/分享码）、TOTP/滑动验证码登录。桌面端（apps/tauri，React）仍是旧形态：无侧边栏无路由，`Gallery.tsx`（945 行）用布尔值切换整页、双行工具栏、功能入口埋在「更多」里、缺探索/收藏页/分享/管理区/搜索/年份导航。本次把桌面端 IA、视觉与功能全面对齐 web 端，同时保留桌面独有能力（导入向导、体检/修复/再平衡、地图、任务中心、本地存储管理）。

## 复用资产

- **图标**：直接复制 webapp 的 SVG sprite（index.html L177-207，29 个 symbol）到桌面 `index.html`，React 里用 `<svg class="ic"><use href="#i-*"/></svg>`，零重复维护
- **设计系统**：把 webapp 的 CSS 变量（`--bg/--fg/--card/--primary/--sidebar-bg…` + `body.theme-light` 覆盖）与组件样式（`.btn` 变体/`.badge`/`.form-card`/`table.admin`/`.ctx-menu`/`.modal`/`.selbar`）移植进 `App.css`，桌面现有暗色变量改名对齐
- **API 层**：`api.ts` 的双 Provider + Proxy 分派保留；远端补齐 webapp 用到的端点（分享列表/创建、ACL、头像、TOTP、admin 用户/组/源/存储/状态、上传进度）

## 文件改动（apps/tauri/src 为主）

### A. 壳与设计系统
- `index.html`：注入 sprite + 更新标题「牧心相册」
- `App.css`：重写为 webapp 配色/组件样式 + 桌面特有样式；`.gallery` 去 max-width 1000px 限制
- 新 `components/Shell.tsx`：**侧边栏**（时间线/探索/相册/分享*/收藏夹/回收站 + 管理区*/存储（本地）/设置；*仅远端）+ **顶栏**（搜索框 + 上传按钮* + 头像）+ **hash 路由**（`#/photos` 等，对齐 webapp 的 route()）+ **头像菜单**（头像上传*、修改密码、两步验证*、深浅主题、锁定/退出）
- `App.tsx`：解锁后渲染 `Shell`（不再直接渲染 Gallery）
- `LockScreen.tsx`：远端登录加**滑动验证码**（移植 webapp initSlider）与 **TOTP 输入行**（`totp_required` 重试），本地口令解锁不变
- 主题：远端模式改为存 localStorage（不再依赖本地 settings），两种模式主题切换都生效

### B. 时间线视图（`views/TimelineView.tsx`，Gallery 拆解）
- 从 `Gallery.tsx`（945 行）拆出：网格渲染 + 数据获取进 `TimelineView`；选择/批量逻辑进共享 hook
- 对齐 webapp：**日分组头恒显**（含「全选当天」复选框 + N 张计数）、**月份分隔条**、**右侧年/月导航轨**（buildYearsRail 同款）、缩略图角标（♥ 收藏 / 动态照片标记）、文件名渐变浮层
- **多选**：圆圈常显（不再切模式）、`.selbar` 批量栏按 webapp 全量对齐（收藏/重命名/分享*/详情/下载/移动到/复制到/回收站/取消）
- **右键菜单**：`photoMenuItems` 同款（预览/收藏/重命名/下载原图/分享*/详情/移动到/复制到/回收站）
- 搜索框过滤 file_name（webapp filteredBlobs 同款）

### C. 灯箱 + 详情
- `Lightbox.tsx`：顶栏按钮对齐（收藏/重命名/分享*/详情/下载/移动到/复制到/回收站/关闭 + 动态照片「播放动态」），左下工具胶囊（＋/－/旋转/水平翻转/垂直翻转/1:1），保留滚轮缩放/拖拽平移/键盘
- `BlobDetailModal.tsx` 保留（本地分片详情），远端模式沿用合成详情

### D. 探索 + 相册
- `views/ExploreView.tsx`：类别（最近添加/照片/视频/动态照片/未入相册）+ 地点（GPS 0.1° 网格聚类），点入复用时间线渲染 + 「← 返回探索」
- `views/AlbumsView.tsx`：封面墙（沿用 HomePage 逻辑）+ 多选相册栏（分享*/删除）+ 新建相册弹窗（替换 window.prompt）；相册详情页（返回/权限*/分享*/删除）+ **ACL 编辑器**（远端，用户/组 tab × 继承/none/view/upload/manage）
- 地图视图保留，入口移到探索页

### E. 分享 + 管理区（仅远端模式）
- `views/SharesView.tsx`：列表（名称/类型/数量/分享码/过期/状态/内容/操作）+ 创建分享弹窗（聚合/逐个 + 有效期 + 分享码）+ 相册分享
- `views/admin/`：用户（卡片墙 + 编辑弹窗含相册权限表）、用户组、同步源、存储管理（测连通）、系统状态（立即同步）
- `api.ts` RemoteProvider 补齐：`/api/shares` 系列、`/api/albums/{id}/acl`、`/api/me/avatar|password|totp/*`、`/api/admin/*`、`/api/blobs/upload`（已有）
- 本地模式：`platform` 能力位控制分享/管理区入口隐藏；保留 StoragePage/SettingsPage/ImportWizard/TaskCenter，挂到侧边栏

### F. 收尾
- 桌面独有功能入口归位：导入向导（时间线页拖拽/按钮）、体检/修复/再平衡（设置或时间线「更多」）
- `window.prompt/confirm` 全部替换为自定义 Modal（对齐 webapp uiConfirm/uiForm）
- `index.html` 标题、回归 `cargo test`（src-tauri e2e 不受前端影响）+ `pnpm build`

## 验证

1. `cargo test --manifest-path core-rs/Cargo.toml --workspace` + `cd apps/tauri/src-tauri && cargo test`（Rust 层回归）
2. `cd apps/tauri && pnpm build`（TS 编译 + 打包）
3. 本地模式手测：解锁 → 侧边栏各页 → 时间线日选/年月轨 → 右键/批量 → 探索 → 导入向导 → 存储/设置/主题
4. 远端模式手测（连接本机 heartshard-server）：登录滑动验证码 + TOTP → 上传入相册 → 分享创建/列表 → ACL 编辑 → 管理区四页 → 头像/改密
5. 视觉对照 webapp（同屏对比侧边栏/网格/灯箱/菜单样式一致性）

## 交付顺序

A → B → C 为第一波（壳 + 时间线 + 灯箱，核心观感对齐），D → E 第二波（探索/相册/分享/管理区），F 收尾发一个 commit 系列，最终 `pnpm tauri build` 出 exe 冒烟。
